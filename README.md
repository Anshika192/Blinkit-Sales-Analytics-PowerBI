# Blinkit Sales Analytics Dashboard

## Project Overview

This project presents an interactive sales analytics dashboard built using Power BI to analyze Blinkit grocery sales data.

The dashboard provides insights into sales performance across different item categories, outlet types, outlet sizes, outlet locations, outlet establishment years, and fat content.

## Tools & Technologies

- Power BI
- MySQL
- SQL
- Python
- Pandas

## Dashboard Pages

### 1. Overview
The Overview dashboard contains key performance indicators and interactive visualizations for:
- Total Sales
- Total Items
- Average Sales
- Total Outlets
- Sales by Item Type
- Sales by Outlet Type
- Sales by Outlet Size
- Sales by Location Type
- Sales by Fat Content

### 2. Detailed Analysis
The Detailed Analysis page provides deeper insights into:
- Sales by Outlet Type
- Sales by Item Type
- Average Sales by Item Type
- Sales by Outlet Establishment Year
- Sales by Outlet Size
- Sales by Outlet Location Type
- Sales by Fat Content

## Key Insights

- Total sales are approximately 1.20M.
- Average sales are approximately 140.99.
- The dataset contains approximately 8.5K item records.
- The analysis covers 10 outlets.
- Medium-sized outlets contribute strongly to overall sales.
- Tier 3 locations show strong sales performance.
- Regular-fat products contribute a larger share of sales than low-fat products.
